description=Map burnt area and burn severity from the differenced Normalised Burn Ratio (dNBR) of Sentinel-2 imagery — either from rasters you already have or by fetching cloud-free scenes from a public STAC catalogue.
about=Computes the differenced Normalised Burn Ratio (dNBR), a seven-class burn-severity raster and a cleaned burnt-area mask over an area of interest. Two algorithms are provided: one differences a pre-fire and a post-fire raster you already have; the other searches a public STAC catalogue (Earth Search / Sentinel-2 L2A by default, no login required) for cloud-free imagery before and after a fire, median-composites a baseline and downloads only the bands it needs. All raster and vector operations use GDAL/OGR and NumPy, which are installed with QGIS, so no extra Python packages are required. A pixel counts as burnt where dNBR exceeds a threshold you set. Not a substitute for field validation of fire extent or severity.

changelog=
    0.1.1 - STAC downloads: new optional "Max scenes per window" cap keeps only the clearest (least-cloudy) scenes for the baseline and post-fire searches, to bound download time and bandwidth (0 = no limit). The per-scene progress bar now advances continuously across both loading phases instead of resetting between them.
    0.1.0 - Initial release: burnt area and burn severity from Sentinel-2 dNBR. "From rasters" differences a pre/post-fire raster pair you supply; "From STAC imagery" fetches cloud-free scenes from a public catalogue (Earth Search / Sentinel-2 L2A). Outputs a dNBR raster, a seven-class severity raster and a cleaned burnt mask, styled automatically, plus an optional full result set (all GeoTIFFs, a summary CSV, polygons and a run manifest). Processing provider + friendly dialog. No extra Python packages required.
